# Mini Shop (مینی‌شاپ) 🛒

یک فروشگاه اینترنتی ساده که با HTML، CSS و JavaScript خالص (بدون هیچ فریم‌ورکی) ساخته شده است.

## ✨ امکانات
- طراحی واکنش‌گرا (Responsive) با پشتیبانی از RTL
- سبد خرید تعاملی (افزایش، کاهش، و محاسبه جمع کل)
- نمایش قیمت‌ها به صورت فارسی
